## Review recurring payments
Repeated subscription charges are candidates for a review. Ask the user whether the service is still useful; a transaction ledger cannot prove non-use. A free trial can turn into a paid recurring charge if it is not cancelled before the trial ends, and a renewal can cost more once a promotional price ends. Savings begin only if cancellation succeeds: follow the company's instructions to cancel, keep a record of the request and any confirmation, and check later statements for charges that continue, which the card issuer can be asked to dispute. This is a demo summary, not an automatic cancellation tool.
